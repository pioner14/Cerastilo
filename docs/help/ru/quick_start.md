# Руководство «Быстрый старт» (Quick Start)

## Шаг 1. Добавление возвещателей (участников)

1. Откройте вкладку **«👥 Возвещатели»**.
2. Нажмите **«➕ Добавить»** в правом верхнем углу. Откроется карточка участника.
3. Заполните карточку.
   - В поле «ФИО» введите имя и фамилию, например Иван Петров.
   - В поле «Пол» выберите «Брат» или «Сестра».
   - В поле «Духовный статус» выберите «Старейшина», «Помощник» или «Возвещатель».
   - Если участник входит в семью другого брата, укажите его в поле «Семья (Глава)». Программа учитывает родство при подборе напарника.
   - В поле «Личный интервал» оставьте «Авто (по типу служения)», чтобы перерыв между заданиями определялся по статусу участника.
4. Откройте **«Квалификации»**. Это третья вкладка карточки, после «Основное» и «Сменный график».
5. Отметьте задания, которые участник может выполнять, например «Чтение Библии (4 мин.)», «Молитва» или «Сокровища (10 мин.)».
6. Нажмите **«Сохранить»**. Участник появится в списке.

Чтобы позже изменить квалификации, дважды щёлкните или коснитесь имени. Можно также выделить участника и нажать **«✏️ Изменить»**. Для автораспределения желательно добавить хотя бы 15–20 участников с разными квалификациями.

## Шаг 2. Создание недель расписания

1. Если нужных недель ещё нет, откройте «📚 Рабочие тетради» на вкладке «⚙️ Настройки».
2. Нажмите **«📁 Выбрать EPUB файл»**. Откроется окно выбора файла.
3. Выберите EPUB-файл рабочей тетради. Недели с программой встреч появятся в дереве дат на вкладке «📅 Расписание».

Если нужны пустые шаблоны на будущий год, нажмите **«➕ Будущий год»** под деревом дат. Подробно — глава 4.2.

## Шаг 3. Запуск автоматического распределения

1. Выберите неделю в дереве слева. Справа откроется таблица заданий.
2. Нажмите **«🪄 Авто-распределение»**. На узком экране кнопка называется **«🪄 Авто»**.
3. Нажмите **«Да»** в окне «Авто-распределение». Программа заполнит свободные места с учётом истории назначений, отпусков и сменных графиков.
4. Проверьте результат. Вы увидите «✅ Распределено: N назначений» или «ℹ️ Все задания уже заполнены», если новых назначений нет. Обратите внимание на жёлтую подсветку и значок ⚠️: они отмечают ручные правки или предупреждения.

## Шаг 4. Ручная корректировка и проверка

1. Щёлкните по ячейке участника. Если она пустая, сразу откроется окно «Выбор участника».
2. Если ячейка заполнена, выберите **«👤 Выбрать / заменить…»** в открывшемся меню.
3. Проверьте список кандидатов. Свободные участники стоят выше занятых. Рядом с именем программа показывает давность последнего задания. Значок ⚠️ и пояснение отмечают конфликт, например отпуск или другое задание на той же неделе.
4. Выберите участника. Его имя появится в ячейке.

## Шаг 5. Экспорт расписания

1. На панели вкладки «📅 Расписание» откройте **«📤 Экспорт»**.
   - Выберите **«📕 PDF…»** для отправки или печати либо **«📝 TXT…»** для простого текста.
   - Для расписания в Word выберите **«📄 Word (DOCX)…»**.
   - Для отдельных листков по учебным заданиям выберите **«🎟️ Советы S-89…»**.
2. Отметьте нужные недели в окне выбора.
3. Нажмите кнопку подтверждения. Откроется окно сохранения.
4. Сохраните файл. В имени расписания программа предлагает месяц и год, название встречи и дату выгрузки.
